# AI-writing-feedback
An AI-powered Django web app that gives students real-time, rubric-based feedback on academic essay drafts. It supports essay submission, student and teacher dashboards, and password-reset flows.

## Configuration

- Copy `.env.example` to `.env`
- Set your database and email values
- Add `ANTHROPIC_API_KEY=<your_key>` to enable real LLM feedback
- `.env` is already ignored by Git so credentials stay local
